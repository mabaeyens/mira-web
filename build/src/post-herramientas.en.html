Tools

May 2026 · First published on LinkedIn, in Spanish

I have been talking about my project for several posts now. That project has a name: Mira.
It comes from a specific need: an AI that goes with me wherever I am, that runs on hardware I already have, that works with my own designs and files and that does not cost an arm and a leg. No third-party services, no data leaving my laptop. I use a Mac. I have tried several options, and since ollama has clear advantages on Apple Silicon, and Gemma 4 is a recent model that aims high, this is my starting point.

Getting the model running is no achievement. You download it, run it from the command line, and in under ten minutes you have local inference. No cost per query. The model reasons, answers, keeps context, until I ask it to help me optimise its execution for the hardware underneath.

My Mac came out in November 2024, but the model's cutoff date is April 2024. So for the model, my laptop does not exist. It is not a design flaw, it is the nature of training: a corpus with a closing date, and everything that happens after does not exist either. The first real problem was not the model, it was its access to more information.

The first answer: add web search. That way, the model can look up what it does not know. It works for my machine's specs, it works for recent news, but finding a page is not the same as reading it. So I add content download. Now it can access the full text, not just the headline. Mira now recommends configuration tweaks that fit my real laptop.

Next problem: I have my own documents, specs in Markdown, that the model cannot see unless I copy and paste them one by one. I add RAG. If it can search the web, it can search my files. Same principle, another source.

The default command line is not practical for daily use. I build a web interface, all local. The next step is mobile, to access it from anywhere.

Mira is not the model. It is what I build on top.

The server is on GitHub, open. The mobile apps are in another repo: I am not a programmer, the code works but I do not guarantee it is good. And who knows what I will want to do with this in the future.

Today I use Mira to review specs and code before handing them to Claude. I save tokens, I do not need dedicated hardware, the laptop is enough. The goal has always been to have the most useful environment, anywhere, on what I already have.

What comes next is making this environment work without waiting for me to switch it on.
