MCP server for on-prem Qlik Sense

Nov 2026 · First published on LinkedIn, in Spanish

The value of AI is in integrating it with the tools we use every day, and one I use daily, of course, is Qlik Sense.

So before the summer I built an MCP server on my own so an LLM can help me with Qlik Sense (tested with Claude and, of course, with local models like Mistral).

For this MCP server, reading is free: from analysing the state of the environment, finding services that are not running or seeing how the repository database is set up, to describing an app, reviewing the reloads that failed over the weekend or finding out why an app may be slow.

Changing anything, though, whether relaunching a reload, adding a chart or touching the script, always takes two steps: first it tells me what it would do without touching anything, and then it does it, only if I approve. It also works with the Windows user I open my Qlik session with, so the MCP sees what I see and nothing more, and it does not store a single password.

Qlik's official MCP server for on-prem Qlik Sense is on its way.

While we wait, and to whet your appetite, I have described how mine is designed.
