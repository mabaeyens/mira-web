When does AI come to Qlik Sense on Windows? Today.

Sep 2026 · First published on LinkedIn, in Spanish

When does AI come to Qlik Sense on Windows?

Today.

It is still impossible to reproduce on-prem what the cloud achieves with its compute capacity. But in an earlier post I said I had spent months working on getting it to run somehow, and today I am publishing the result.

How?

With an extension that is easy to install and opens an AI assistant where you can ask questions about the data in your Qlik Sense apps, with cloud models (in my case, Claude) or with local models.

Local models?

Yes. One of the fears about these new technologies is who ends up with access to the data, and therefore to your business. With a local model, the answer is simple: only you.

How is this extension built?

Using Qlik Sense's public, documented APIs.

Since I work with Anthropic's Claude much more than with any other cloud model provider, the code is set up to use an Anthropic API key and send questions straight to Haiku, Sonnet or Opus. This API is compatible with OpenAI and other models too.

Locally, I used ollama as the server for simplicity, and Ministral 3 3B and 8B as local models, because everything has to run on my laptop.

All of this is configurable.

What for?

As it stands, the extension is useful for something: turning information and charts into explanations anyone can understand, and generating new charts for your app.

As a final product, I am sure you will want to tweak it and adapt it to the reality of your companies, and that is the point: to show it is possible, and that with a little imagination, it is just a matter of getting started.

Why?

What I find most valuable is the research and integration exercise this extension represents. We all use AI in a lot of what we do (more and more), and the real value is in integrating this new technology with our everyday tools.

I actively maintain this extension in my spare time, so you can file issues on GitHub and I will get to them (along with more things I want to add on my own) at some point.

Where?

The repository with the code, the extension ZIP and the documentation are at github.com/mabaeyens/AnthropicExtension.

This is not magic, gentlemen.
