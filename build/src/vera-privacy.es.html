Política de privacidad

Última actualización: 2026-07-06

Vera está hecha pensando primero en la privacidad, y esta política es breve porque hay muy poco que decir.

Lo esencial

  • Sin cuenta. Sin registro. Sin seguimiento. Sin analíticas. Sin anuncios.
  • Sin servidores propios. Vera no tiene backend. No existe ninguna «nube de Vera» a la que enviar nada.
  • Tus archivos siguen siendo tuyos. Vera lee y escribe los archivos Markdown de la carpeta que elijas, en tu iCloud Drive o en tu dispositivo. Nunca pasan por nosotros.
  • Código abierto. El código completo está en GitHub, así que puedes comprobar cada palabra de esto: github.com/mabaeyens/vera-apps.

Qué datos recopila Vera

Ninguno. Vera no recopila, transmite ni vende datos personales. No podríamos hacerlo: no hay servidor ni SDK de analíticas.

Datos que se quedan en tu dispositivo

  • La carpeta que eliges se recuerda mediante un marcador con ámbito de seguridad guardado en el Llavero de tu dispositivo.
  • Las preferencias pequeñas (tamaño de letra, linter activado o no, modo foco, últimos archivos abiertos) viven en los ajustes locales de la app.

Ambos se quedan en tu dispositivo y solo se sincronizan a través de tu propio iCloud, bajo tu Apple ID, nunca con nosotros.

La única actividad de red

Vera no hace llamadas de red por su cuenta, con dos excepciones sinceras:

  1. Imágenes remotas en tu Markdown. Si un archivo que abres hace referencia a una imagen por URL (![](https://…)), Vera descarga esa imagen para mostrarla, igual que un navegador. La petición va directamente al servidor de la imagen, no a nosotros. Si nunca abres archivos así, esto no ocurre.
  2. GitHub (opcional). Cuando conectas un repositorio, Vera habla directamente con la API de GitHub usando un token de acceso, que se obtiene pegando un token de acceso personal de ámbito reducido que creas tú, o iniciando sesión con el OAuth Device Flow de GitHub (apruebas un código en github.com y GitHub entrega el token directamente a la app). De cualquier forma, el token se guarda solo en el Llavero de tu dispositivo, no se sincroniza en ningún sitio, ni siquiera por iCloud, y nunca pasa por ningún servidor nuestro. La lista de repositorios que has añadido se sincroniza entre tus dispositivos mediante el almacén clave-valor de iCloud, bajo tu Apple ID, nunca con nosotros.

Privacidad de los menores

Vera no recopila datos de nadie, tampoco de menores.

Cambios

Si esta política cambia alguna vez, la actualización llegará primero a PRIVACY.md en el repositorio público, y esta página se mantendrá sincronizada.
