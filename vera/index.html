Vera · In beta · iPhone, iPad, Mac

The native Apple app for the Markdown in your repos.

Your AI agents write a lot of Markdown: AGENTS.md, CLAUDE.md, specs, run logs, PR notes. It lives in your git repos, not iCloud. Vera reads it natively, lets you steer it, and commits it back.

It also opens every .md in your iCloud Drive, with zero setup.

What it does

GitHub-native

Sign in with one-tap OAuth, browse a repo's Markdown tree in the sidebar, and open files in tabs. Switch branches, commit straight to one (several files in a single atomic commit), or open a pull request. “What Changed” renders a native diff when a file moves on.

One tree for everything

Every .md in your iCloud Drive or local folder and each connected repo collapse in the same leading-chevron sidebar, with lazy per-folder expansion. No vaults, no projects, a transparent window into files you already have.

Read and write, natively

A syntax-highlighted SF Mono editor and a rendered preview with code blocks and tables. A live linter with one-tap auto-fix, snippet insertion, and a Focus Mode that strips the chrome so the Markdown reads.

Private by design

Your token stays in the device Keychain and is never synced or sent anywhere. New files and edits work offline and sync over your own iCloud on reconnect. Adaptive dark and light.
